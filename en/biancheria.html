Linen service

Included in the price

- one set of bed linen for each guest
- a single set of complimentary towels.

If you’d rather not bring towels from home, you can request additional towel sets at laundry cost.

Towel set

A towel set includes:

- 1 large bath towel
- 1 face towel
- 1 small hand towel

Each additional towel set costs €10.
